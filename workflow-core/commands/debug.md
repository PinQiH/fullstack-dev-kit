# /debug — 系統化除錯

載入 `debugger` skill，以結構化流程分析並排除程式碼問題。

## 觸發時機

- 遇到錯誤訊息、例外、崩潰
- 行為不如預期，但原因不明
- 正式環境事件調查
- 間歇性 / 難以重現的 bug

## 執行流程

1. **載入除錯 skill**：載入 `debugger` skill 取得完整除錯框架
2. **收集問題資訊**：
   - 錯誤訊息與完整 stack trace
   - 觸發步驟（如何重現）
   - 環境資訊（Node 版本、OS、相關設定）
   - 最近的程式碼變更
3. **形成假設清單**：依可能性排序，逐一驗證
4. **找出根本原因**：不停留在表面症狀
5. **修復並驗證**：補測試案例防止退化

## 輸出格式

產出結構化的除錯分析報告，包含：
- 問題描述、環境資訊、錯誤分析
- 假設清單（依優先權）
- 調查步驟
- 根本原因
- 修復方案
- 預防措施

## 使用範例

```
/debug TypeError: Cannot read properties of undefined (reading 'userId')
  at getUserOrders (orderService.js:42)
```

```
/debug API 偶爾回傳 500，無固定規律，高流量時更頻繁
```
