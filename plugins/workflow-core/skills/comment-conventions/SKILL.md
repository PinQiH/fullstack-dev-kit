# 程式碼註解規範（Todo-Tree）

撰寫或修改任何程式碼時，一律使用以下標記格式。這些標記與 Todo-Tree 擴充套件整合，請嚴格遵守，不得自創其他格式。

## 標記對照表

| 用途 | 格式 | 範例 |
|------|------|------|
| 區塊標題（Section / Block） | `// > 標題名稱` | `// > 驗證流程` |
| 函式與方法（Function / Method） | `// - 函式標題` | `// - 取得使用者資料` |
| 特殊標記或重點 | `// @ 標記內容` | `// @ 依賴外部 API，注意 timeout` |
| 待辦事項 | `// TODO: 內容` | `// TODO: 補上分頁邏輯` |
| 需要修復的錯誤 | `// FIXME: 內容` | `// FIXME: 邊界值未處理` |
| 有疑問需確認的邏輯 | `// ?? 內容` | `// ?? 這裡應該用 findOne 嗎` |
| 嚴重警告或地雷 | `// !! 內容` | `// !! 改這裡會影響報表模組` |

## 使用規則

- 標記與內容之間保留一個空格
- 標記文字使用繁體中文
- 程式碼本體（變數名、函式名）保留英文，僅註解與說明使用中文
- 不在程式碼本體中使用 emoji
- `// TODO:` 和 `// FIXME:` 冒號後加空格，與 Todo-Tree 預設設定一致
